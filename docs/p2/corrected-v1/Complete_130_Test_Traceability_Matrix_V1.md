## 1. Interpretation and prerequisite codes

- **G1:** exact P1 execution approval + applied P1 + controlled fixtures.
- **G2:** accepted P1 + reviewed corrected/approved P2 contract + implemented P2 + verified identities + controlled harness.
- **G3:** accepted P2 + separately authorized P3 workflows + initialized profiles + current Auth lookup.
- **G4:** separately approved P4 lifecycle + prior prerequisites.
- **G9:** separately approved P9 verified-UUID/platform operations.
- **GD:** relevant deployed feature + approved S08 limits/budgets/request policy.

Primary phase is the earliest phase that can satisfy the **complete parent test**. Mandatory earlier subsets remain required; passing one never marks the parent passed. Independent sessions are mandatory for all identified race cases, including OWN-06/07/08, INV-06/07, ACC-04/09/10/11, LIFE-02 concurrent retries, NEW-P1-05, NEW-P2-07/08, NEW-P3-01/02/04/09/10/11/12, NEW-P9-01 and NEW-DEP-02/04. Deferred-validator cases must actually reach commit-time evaluation or explicitly force constraints in an authorized transaction.
